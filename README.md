# TESSA

**Transindent Executive Service & Support Assistant**

TESSA is an AI-powered front-desk agent built for **Transindent Miami**, a fictional luxury hotel environment used to prototype an intelligent, adaptive hotel receptionist.

Unlike a traditional FAQ chatbot, TESSA is designed to evolve beyond static responses. The long-term goal is to build an agent that can remember interactions, learn from corrections and feedback, use hotel systems as tools, and continuously improve how it handles guest requests.

### Current capabilities

* Natural-language guest conversations
*  Hotel information and policy handling
*  FAQ retrieval
*  Conversation context
*  FastAPI backend
*  LLM-powered responses
*  React-based chat interface

### Planned

* Persistent guest/conversation memory
* Appointment and reservation management
* Calendar and hotel-system integrations
* Human handoff and escalation
* Interaction feedback and evaluation
* Automatic identification of mistakes and knowledge gaps
* Continuous improvement from real interactions
* Agent analytics and performance monitoring

TESSA is currently a prototype, with the goal of evolving it into a more autonomous **AI front-office system** rather than simply another hotel chatbot.
